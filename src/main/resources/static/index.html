What does "Running / Stopped" mean?
When the pipeline is running, the service actively watches the source folder for new media files and automatically retries failed jobs on a schedule. It is the normal operating mode.

When the pipeline is stopped, the file monitor and retry scheduler are paused — no new files will be picked up and no retries will happen. Files already in progress will finish, but nothing new starts. Existing records and logs are untouched.

Play ▶ — Resumes the pipeline. All previous file-tracking state is discarded and the source folder is re-scanned from scratch, so any files sitting there will be picked up as if they were just detected.
Stop ■ — Pauses the pipeline immediately. Use this if you need to move files manually, change settings, or troubleshoot without the service interfering.
